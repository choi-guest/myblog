마크다운 파일을 쓰면 바로 글이 되는 작은 블로그를 만들었습니다. 프레임워크도 빌드 도구도 없이 **HTML, CSS, JavaScript**만으로 동작합니다.

## 새 글 쓰는 법

1. `posts/` 폴더에 `my-new-post.md`처럼 영문 소문자와 하이픈으로 된 이름의 파일을 만듭니다.
2. 파일 맨 위에 프론트매터를 적고, 그 아래에 본문을 씁니다.
3. `posts/index.json`에 글 정보를 추가합니다.

프론트매터는 이렇게 씁니다.

```markdown
---
title: 글 제목
date: 2026-10-27
tags: [태그1, 태그2]
description: 목록에 보일 짧은 요약
---
```

`index.json`에는 같은 정보를 `slug`와 함께 넣습니다. 파일 이름에서 `.md`를 뺀 것이 `slug`입니다.

```json
{ "slug": "my-new-post", "title": "글 제목", "date": "2026-10-27", "tags": ["태그1"], "description": "짧은 요약" }
```

## 로컬에서 보기

브라우저는 보안 때문에 `file://`로 연 페이지에서 다른 파일을 읽지 못합니다. 그래서 간단한 로컬 서버가 필요합니다.

```bash
python -m http.server 8000
```

그다음 <http://localhost:8000> 에 접속하면 됩니다.
