# Plan 서브에이전트 지침

## 역할
`/apps/starfighter/` 웹앱의 계획서 `spec.md`를 작성한다. 코드는 쓰지 않는다.

## 수정 범위
- 새로 만드는 파일: `apps/starfighter/spec.md` 하나만.
- 그 밖의 파일은 읽기만 한다. 블로그 파일과 `.claude/`, 다른 앱 폴더는 수정하지 않는다.
- 참고용으로 `apps/element-alchemy/spec.md`의 구성(장 구분, 체크리스트 형식)을 읽어도 좋다.

## 웹앱 개요 (사용자 요청)
- 제목: **스타파이터** (StarFighter)
- 장르: 화면 아래쪽 전투기를 좌우(필요하면 상하 일부)로 움직이며 위에서 오는 적 편대를 쏘아 떨어뜨리는 **고전 아케이드풍 종스크롤/고정 화면 슈팅**.
- 사용자는 "고전 우주 슈팅 게임과 비슷한 방식"을 원한다. 장르의 일반 요소(적 무리가 대형을 이루고, 일부가 내려와 돌진하며 탄을 쏘고, 플레이어는 목숨이 있고, 웨이브를 깨면 다음 단계)는 써도 된다.
- **난이도 10단계**: 단계 선택 화면, 깬 단계까지 잠금 해제(localStorage, try/catch). 단계가 오를수록 적 수·속도·돌진 빈도·적 탄 밀도·새 적 유형이 늘어난다. 5단계와 10단계는 우두머리 적.
- 점수판: 점수, 최고 점수, 남은 목숨, 현재 단계.
- 조작: PC 방향키/WASD + 스페이스(발사), 모바일은 화면 끌기 이동 + 자동 발사, 일시정지 버튼.

## 반드시 지킬 것: 특정 기존 게임의 복제 금지
갤러그(Galaga)·갤럭시안(Galaxian)·스페이스 인베이더 등 특정 기존 게임을 재현하지 않는다. 다음은 **쓰지 않는다**:
- 적이 플레이어 기체를 광선으로 끌어가 포획하고, 되찾으면 쌍발 기체가 되는 규칙
- "챌린징 스테이지" 같은 보너스 스테이지 구조와 이름
- 원작의 적 디자인(벌·나비·보스 갤러그 모양), 기체 디자인, 효과음, 색 배치, 화면 문구, 대형 배치와 진입 궤적
대신 이 게임만의 요소를 최소 2가지 정한다(예: 단계별 보조 무기 선택, 적 유형별 고유 행동, 우두머리의 독자 패턴, 콤보 배율 등). spec에 "기존 게임과의 차별점" 표를 넣는다.

## 지켜야 할 규칙 (CLAUDE.md)
- HTML, CSS, JavaScript만. 외부 라이브러리 최소화(CDN 허용이지만 필요 없도록 설계). Canvas 2D 사용 권장. 그래픽은 코드로 그린 도형이나 직접 만든 SVG.
- `/apps/starfighter/` 안에서 자체 완결.
- 모바일 사용 가능(375px, 가로 스크롤 없음, 터치 대상 44px 이상, 화면 끌기 중 페이지 스크롤 방지).
- 라이트/다크(prefers-color-scheme) 지원, UI 텍스트 대비 WCAG AA.
- `<html lang="ko">`, charset, viewport. prefers-reduced-motion 존중(화면 흔들림·번쩍임 줄이기).
- 게임 로직은 DOM 접근 없는 순수 모듈로 분리, 난수·시간 주입 가능하게. innerHTML 금지.

## spec.md에 담을 내용
1. 게임 소개, 기존 게임과의 차별점 표
2. 상세 규칙: 화면·좌표, 플레이어(이동 속도, 탄, 목숨, 무적 시간), 적 유형별 행동, 웨이브 구성, 우두머리, 아이템/보조 무기, 충돌 판정, 단계 클리어/게임 오버
3. **10단계 난이도 표**: 단계별 적 수, 속도, 돌진 빈도, 적 탄 밀도, 등장 적 유형, 특수 요소
4. 점수 규칙
5. 화면 구성: 시작/단계 선택, 게임 화면 HUD, 일시정지, 단계 클리어, 게임 오버
6. 조작과 접근성
7. 파일 구조와 각 역할
8. 블로그 카드용 정보(제목, 한 줄 설명, 미리보기 이미지)
9. Review 체크리스트

한국어로 작성한다. 끝나면 핵심 규칙 5줄 이내 요약과 차별점을 보고한다.
