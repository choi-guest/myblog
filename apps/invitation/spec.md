# 모바일 초대장 계획서

## 1. 목표
카카오톡·문자로 링크를 받아 휴대폰에서 바로 여는 한 장짜리 초대장. 위에서 아래로 넘기며 읽고, 행사까지 남은 시간과 오시는 길을 한눈에 본다.

## 2. 화면 구성 (위에서 아래 순서)

| 순서 | 구역 | 내용 |
|---|---|---|
| 1 | 표지 | 대표 사진(화면 높이 가득), 제목, 행사 날짜·요일·시간, 장소명 |
| 2 | 인사말 | 초대 문구 3~5줄, 초대하는 사람 이름 |
| 3 | 일시와 D-Day | 큰 글씨 "D-23", 그 아래 "23일 4시간 12분 30초 남았습니다", 달력(행사 달, 행사일 표시) |
| 4 | 오시는 길 | 카카오맵(마커 + 장소명), 주소와 [주소 복사], [카카오맵 길찾기]·[네이버 지도]·[티맵] 버튼, 지하철·버스·주차 안내 |
| 5 | 연락처 | 초대하는 사람별 [전화]·[문자] 버튼 |
| 6 | 공유 | [링크 복사], [공유하기](휴대폰 공유 창, 지원할 때만) |
| 7 | 바닥글 | 짧은 감사 문구 |

선택 기능(원하면 추가): 사진 모음(가로로 넘기기), 참석 여부 응답, 배경 음악.

## 3. D-Day 규칙
- 기준: `config.js`의 행사 일시(한국 시간).
- 날짜 수는 한국 시간 달력 날짜 차이로 센다.
  - 행사 전: "D-n" + 남은 일·시·분·초(1초마다 갱신)
  - 행사 당일(0시~23시 59분): "D-Day 오늘입니다"
  - 행사 후: "D+n 행사가 끝났습니다", 카운트다운은 숨김
- 탭을 다시 열면 바로 다시 계산한다.
- 시험: Node에서 전날 23:59, 당일 00:00, 행사 시각 직전·직후, 다음 날 00:00을 넣어 결과를 확인한다.

## 4. 지도 규칙 (카카오맵)
- 카카오 JavaScript 키로 SDK를 불러온다. 허용 도메인에 `http://localhost:8000`과 배포 주소를 등록해야 한다.
- 처음에는 지도를 움직일 수 없게 둔다. 휴대폰에서 페이지를 넘기다 지도가 손가락을 잡아채지 않게 하기 위해서다. [지도 크게 보기]를 누르면 움직일 수 있다.
- 키가 없거나 불러오기에 실패하면 지도 칸에 주소와 길찾기 버튼만 보여 준다.

## 5. 파일 구조
```
invitation/
├── index.html
├── css/style.css
├── js/
│   ├── config.js   # 행사 정보와 카카오 키 (자리표시로 시작)
│   ├── dday.js     # D-Day 계산 순수 함수
│   ├── map.js      # 카카오맵, 길찾기 링크
│   └── main.js     # 화면 연결
├── images/
│   ├── cover.jpg   # 대표 사진 (없으면 무늬 배경으로 대체)
│   └── og.jpg      # 공유 미리보기 1200×630
└── serve.mjs       # 로컬 서버
```

## 6. config.js에 들어갈 정보 (사용자에게 받을 것)
| 항목 | 예시 | 상태 |
|---|---|---|
| 행사 종류 | 결혼식 / 돌잔치 / 생일 / 모임 | 미정 |
| 제목 | ○○ ♥ ○○ 결혼합니다 | 미정 |
| 일시 | 2026-12-12 12:00 | 미정 |
| 장소명·주소 | ○○웨딩홀 3층, 서울시 ... | 미정 |
| 좌표 | 주소로 찾아서 넣음 | 주소 받은 뒤 |
| 초대하는 사람·연락처 | 이름, 전화번호 | 미정 |
| 인사말 | 직접 쓰거나 예시에서 고름 | 미정 |
| 대표 사진 | 1장 | 미정 |
| 카카오 JavaScript 키 | 개발자 사이트에서 발급 | 미정 |

정보가 오기 전까지는 자리표시로 만들고, 받는 대로 `config.js`만 바꾼다.

## 7. 디자인 방향
- 기본: 따뜻한 흰 배경, 진한 회갈색 글자, 포인트 색 1개(행사 종류에 맞춰 고름).
- 제목만 붓글씨 느낌 웹폰트 1종, 본문은 시스템 폰트.
- 구역이 화면에 들어올 때 살짝 떠오르는 효과(움직임 줄이기 설정이면 끔).
- 폭 480px까지 가운데 정렬. PC에서 열어도 휴대폰 모양으로 보인다.

## 8. 진행 순서
1. 계획 승인
2. 뼈대 만들기: 자리표시 정보로 전체 화면과 D-Day 완성 (키 없이 확인 가능)
3. 지도 연결: 카카오 키를 받으면 지도와 길찾기 연결
4. 확인: 375px·320px 화면, 라이트/다크, D-Day 경계 시험, 콘솔 오류
5. 실제 정보 입력과 사진 넣기
6. 배포(선택): GitHub Pages 등에 올려 링크 만들기 → 카카오 허용 도메인에 등록

## 9. 확인 목록
- [ ] 가로 스크롤 없음(375px, 320px)
- [ ] D-Day 전·당일·후 문구가 맞음
- [ ] 지도 표시, 키 없을 때 대체 화면
- [ ] 길찾기·전화·문자·주소 복사·링크 복사 동작
- [ ] 버튼 44px 이상, 아이폰 노치·홈 바 영역에 가리지 않음
- [ ] 라이트/다크 모두 잘 보임, 콘솔 오류 없음
- [ ] 카카오톡 공유 미리보기(제목·사진) 표시
