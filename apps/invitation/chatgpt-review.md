# 모바일 초대장 코드 리뷰

## 1. 요약

전반적인 구조는 명세를 잘 따르고, D-Day 계산은 한국 시간대 오프셋을 사용해 기기 시간대와 무관하게 한국 달력 날짜 기준으로 처리합니다. `textContent`/요소 생성, `100dvh`와 safe-area, 감소된 움직임 설정, 지도 SDK 실패 대체 화면도 갖춰져 있습니다.

배포 전 공유 미리보기 URL을 완성해야 하며, 로컬 서버는 프로젝트 루트 안의 비공개 파일까지 노출할 수 있습니다. 또 JavaScript가 실행되지 않으면 주요 구역이 보이지 않고, 지도 조작 버튼은 프로젝트의 최소 터치 크기 기준보다 작습니다.

## 2. 발견한 문제

### 중간 — 정적 서버가 프로젝트 내부 파일을 외부 인터페이스에 공개함

- 위치: `serve.mjs:26-35`, `serve.mjs:40`
- 재현: `node serve.mjs` 실행 후 `http://localhost:8000/.git/config` 또는 프로젝트 안의 다른 파일 경로를 요청하면 루트 아래의 파일이 그대로 응답됩니다. 서버는 기본 호스트를 지정하지 않아 네트워크 인터페이스에도 바인딩됩니다. 같은 네트워크의 다른 기기에서도 접근할 수 있는 환경이라면 저장소 메타데이터나 향후 추가될 비공개 파일이 노출될 수 있습니다.
- 수정 제안: 공개 대상 파일/디렉터리만 허용하는 경로 allowlist를 적용하고 `.git` 등 비공개 경로를 거부하세요. LAN 접속이 필요하지 않다면 `127.0.0.1`에만 바인딩하세요.

### 중간 — JavaScript가 실패하면 대부분의 본문이 계속 숨겨짐

- 위치: `css/style.css:372-378`, `js/main.js:193-210`
- 재현: 브라우저에서 JavaScript를 끄거나 모듈 초기화가 오류로 중단된 상태로 페이지를 열면 `.reveal` 구역은 기본 `opacity: 0` 상태이고, 이를 표시하는 `setupReveal()`도 실행되지 않습니다. 인사말, 일시, 오시는 길, 연락처, 공유 구역을 읽을 수 없습니다.
- 수정 제안: 기본 CSS에서는 구역을 표시하고, JavaScript가 준비된 뒤에만 숨김/등장 효과 상태를 활성화하세요. 그러면 스크립트가 실패해도 콘텐츠를 읽을 수 있습니다.

### 낮음 — 공유 미리보기 태그가 배포 URL을 식별하지 못함

- 위치: `index.html:10-14`
- 재현: 배포해 카카오톡 등에서 URL 미리보기를 요청하면 `og:image`가 `images/og.jpg`라는 상대 경로라 크롤러가 이미지 절대 URL을 얻지 못할 수 있고, `og:url`도 없어 페이지의 대표 URL을 명시하지 않습니다. 실제 이미지가 아직 없다는 점과 별개로, 배포 후 태그 값이 이 상태라면 미리보기 이미지/정규 URL 처리가 불완전합니다.
- 수정 제안: 배포 시 `og:image`를 `https://...` 절대 주소로 바꾸고, `og:url`에 실제 초대장 페이지의 절대 주소를 추가하세요. `og:title`과 `og:description`도 행사별 문구로 갱신하세요.

### 낮음 — 지도 조작 버튼이 최소 터치 높이보다 작음

- 위치: `css/style.css:252-267`
- 재현: 지도 아래쪽의 `지도 움직이기` 버튼은 `min-height: 40px`로 지정되어 있어 프로젝트의 44×44px 터치 대상 기준을 충족하지 않습니다. 모바일에서 누르기 어렵거나 인접한 지도 컨트롤과 오작동할 가능성이 있습니다.
- 수정 제안: 버튼 높이를 최소 44px로 맞추세요.

## 3. 잘된 점

- `getDday()`가 UTC epoch에 한국 시간 오프셋을 적용해 날짜를 비교하므로, 당일·전후 경계가 기기의 시간대 설정에 좌우되지 않습니다.
- 카운트다운 숫자에는 `aria-live`가 없고 D-Day 레이블만 변경 시 갱신됩니다. `textContent`와 DOM 요소 생성을 사용해 행사 문구를 안전하게 렌더링합니다.
- 지도는 기본 비조작 상태이며 키/SDK 오류에는 대체 안내가 있습니다. 외부 지도 링크에 `rel="noopener"`도 지정되어 있습니다.
