# CLAUDE.md

## 프로젝트 개요

스마트폰에서 보기 좋은 **모바일 반응형 초대장 웹페이지**. 링크 하나로 열어 보는 한 장짜리 페이지다.

- 프레임워크·빌드 도구 없이 **HTML, CSS, JavaScript만** 쓴다. npm, 번들러, `package.json`을 만들지 않는다.
- 외부 라이브러리는 쓰지 않는다. 예외는 **카카오맵 JavaScript SDK** 하나다. 카카오 키가 없을 때는 키가 필요 없는 구글 지도 삽입(iframe)으로 대신한다.
- 핵심 기능은 두 가지다.
  1. **D-Day**: 행사일까지 남은 시간
  2. **장소 지도**: 카카오맵

## 파일 구조

```
invitation/
├── index.html        # 초대장 페이지 (진입점)
├── css/
│   └── style.css     # 전체 스타일 (테마 변수, 레이아웃)
├── js/
│   ├── config.js     # 행사 정보: 제목, 일시, 장소명, 주소, 좌표, 연락처 (수정은 여기서만)
│   ├── dday.js       # D-Day 계산 (순수 함수, DOM 접근 없음)
│   ├── map.js        # 카카오맵 초기화와 길찾기 링크
│   └── main.js       # DOM 연결, 초기화
├── images/           # 대표 사진, 공유용 미리보기 이미지
└── serve.mjs         # 로컬 미리보기 서버 (Node 기본 모듈만 사용)
```

행사 정보는 모두 `js/config.js`에 모은다. 날짜·장소가 바뀌어도 HTML이나 다른 JS를 고칠 필요가 없게 한다.

## 실행 방법

카카오맵 SDK는 등록된 도메인에서만 동작하고, ES 모듈은 `file://`에서 막히므로 로컬 서버로 연다.

```bash
node serve.mjs 8000
```

그다음 http://localhost:8000 에 접속한다. 휴대폰 화면은 브라우저 개발자 도구의 모바일 보기(375×812)로 확인한다.

## 기능 명세

### 1. D-Day
- `config.js`의 행사 일시(한국 시간, `2026-12-12T12:00:00+09:00`처럼 시간대를 붙인 형식)를 기준으로 계산한다.
- 표시 형식:
  - 행사 전: "D-23", 그 아래 "23일 4시간 12분 30초 남았습니다"
  - 행사 당일: "D-Day", "오늘입니다"
  - 행사 후: "D+3", "행사가 끝났습니다"
- 날짜 단위 D-Day는 **달력 날짜 기준**으로 센다(남은 시간을 24시간으로 나눠 반올림하지 않는다). 한국 시간 자정을 넘으면 하루가 줄어든다.
- 남은 시간은 1초마다 갱신한다. 탭이 숨겨졌다 돌아오면(`visibilitychange`) 바로 다시 계산한다.
- 계산 함수는 `dday.js`에 `getDday(now, eventDate)` 같은 순수 함수로 두어 Node에서 테스트할 수 있게 한다. 현재 시각은 인자로 주입한다.
- 숫자가 바뀔 때 화면 낭독기가 매초 읽지 않도록, 초 단위 카운트다운에는 `aria-live`를 쓰지 않는다. D-Day 문구에만 `aria-live="polite"`를 쓴다.

### 2. 장소 지도 (카카오맵)
- 카카오 개발자 사이트에서 발급한 **JavaScript 키**를 쓴다. 키는 `config.js`에 둔다.
  - JavaScript 키는 브라우저에 노출되는 키이므로 저장소에 올려도 되지만, 카카오 개발자 콘솔에서 **허용 도메인**을 반드시 등록해 다른 사이트에서 못 쓰게 한다. `localhost:8000`과 실제 배포 도메인을 등록한다.
  - REST API 키나 Admin 키는 절대 넣지 않는다.
- SDK는 `autoload=false`로 불러오고 `kakao.maps.load()` 안에서 지도를 만든다.
- 지도에 장소 마커와 장소명 표시. 확대·축소 버튼을 넣고, 휴대폰에서 페이지를 스크롤할 때 지도가 손가락을 가로채지 않게 한다(`draggable: false` 기본, "지도 크게 보기"를 누르면 조작 가능).
- 좌표(`lat`, `lng`)를 비워 두면 카카오 키가 있을 때 `services` 라이브러리로 주소에서 좌표를 찾는다.
- 지도 아래 버튼:
  - **카카오맵 길찾기**: 좌표가 있으면 `https://map.kakao.com/link/to/장소명,위도,경도`, 없으면 `https://map.kakao.com/link/search/검색어`
  - **네이버 지도**: `https://map.naver.com/p/search/검색어` (티맵은 별도 키가 필요해 넣지 않음)
  - **주소 복사**: `navigator.clipboard.writeText`, 실패하면 주소를 복사할 수 있게 보여 준다
- 키가 없거나 SDK·좌표 찾기에 실패하면 구글 지도 삽입(`maps.google.com/maps?q=검색어&output=embed`)으로 지도를 보여 준다.

### 3. 그 밖의 구성 (권장 순서)
1. 표지: 대표 사진, 제목, 일시
2. 초대 인사말
3. 일시와 D-Day
4. 오시는 길: 지도, 주소, 교통 안내(지하철·버스·주차)
5. 연락처: 전화(`tel:`)·문자(`sms:`) 버튼
6. 공유: 링크 복사, `navigator.share`(지원할 때만 표시)

## 디자인 규칙

- **모바일 우선**: 기본 스타일은 360~430px 폭 기준으로 쓰고, 넓은 화면은 `min-width` 미디어 쿼리로 가운데 정렬(최대 폭 480px)만 한다.
- 어떤 화면에서도 가로 스크롤이 없어야 한다. 좌우 여백은 최소 20px.
- 터치 대상(버튼, 링크)은 최소 44×44px.
- 아이폰 노치·홈 바를 고려해 `env(safe-area-inset-*)`를 쓴다. 화면 높이는 `100vh` 대신 `100dvh`.
- 색은 `:root`의 CSS 변수로만 정의한다. 다크 모드는 `prefers-color-scheme`를 따르되, 초대장 분위기를 해치지 않도록 대비만 맞춘다.
- 폰트는 시스템 폰트 스택을 기본으로 한다. 웹폰트를 쓴다면 제목용 1종만, `font-display: swap`.
- 한글 줄바꿈: `word-break: keep-all; overflow-wrap: break-word;`
- 애니메이션은 짧고 부드럽게, `prefers-reduced-motion`이면 끈다.
- 이미지는 `loading="lazy"`(표지 제외), 폭·높이 속성을 넣어 레이아웃이 밀리지 않게 한다. 대표 사진은 1MB 이하로 줄인다.

## 공유 미리보기

카카오톡·문자로 링크를 보내면 미리보기가 뜨도록 `<head>`에 Open Graph 태그를 넣는다: `og:title`, `og:description`, `og:image`(1200×630, 절대 주소), `og:url`.

## 코딩 규칙

- HTML: `<html lang="ko">`, `<meta charset="utf-8">`, `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`. 시맨틱 태그(`header`, `main`, `section`, `footer`) 사용.
- JavaScript: ES 모듈, `const`/`let`만, 세미콜론, 2칸 들여쓰기, UTF-8.
- `innerHTML` 금지. `textContent`와 요소 생성으로 그린다.
- CSS 클래스명은 소문자-하이픈. `!important` 지양.
- 개인정보(실명, 전화번호, 계좌번호)는 `config.js`에만 두고, 저장소를 공개할 때는 사용자에게 먼저 확인한다.

## 작업 규칙

- 승인 없이 구현을 시작하지 않는다. 먼저 계획을 보여 주고 승인을 받는다.
- 행사 정보(날짜, 장소, 문구)가 없으면 지어내지 말고 `config.js`에 "여기에 입력" 같은 자리표시를 두고 사용자에게 묻는다.
- 막히면(카카오 키 문제, 도메인 등록 등) 우회하지 말고 사용자에게 알린다.

## 작업 후 확인 사항

1. 휴대폰 폭(375px)과 작은 폭(320px)에서 가로 스크롤이 없는지
2. D-Day가 행사 전·당일·후에 맞게 바뀌는지 (Node로 `getDday`에 날짜를 넣어 확인)
3. 지도가 뜨는지, 키가 없을 때 구글 지도로 대신 나오는지
4. 길찾기·전화·주소 복사 버튼이 동작하는지
5. 라이트/다크 모드 모두 글자가 잘 보이는지
6. 브라우저 콘솔에 오류가 없는지
