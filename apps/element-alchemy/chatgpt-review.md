# 원소 연금술 독립 코드 리뷰

## 1. 요약

**판정: 수정 필요 (낮음).** 기존 리뷰에서 지적한 애니메이션 중 새 게임 시작, 한글 입력 상태 WASD, 안내 문구, 스타일 변수, 화면 폭, 도감 배치, 테스트 API 문제는 현재 코드에서 반영된 것을 확인했습니다. 다만 최고 점수 저장값을 읽을 때 일부 손상된 문자열이 정상 점수로 처리됩니다. 이 검토는 명세·기존 리뷰·수정 내역과 코드 대조를 기준으로 했으며 브라우저 동작이나 게임 로직 테스트는 실행하지 않았습니다.

## 2. 발견한 문제

### [낮음] 숫자 뒤 문자가 붙은 손상 저장값을 최고 점수로 받아들임

- **위치**: `js/storage.js:7-8`
- **문제와 재현**: `Number.parseInt`는 문자열 앞부분만 읽습니다. 브라우저 개발자 도구에서 `localStorage.setItem('element-alchemy:best', '123oops')`를 실행한 뒤 페이지를 열면, 손상된 값인데도 최고 점수가 `123`으로 표시됩니다. `'1e6'`도 `1`로 처리됩니다. 명세는 손상된 저장값에서 0으로 처리하도록 요구하며, 기존 `review.md`도 손상값은 0이라고 기록했지만 이 형식의 값은 걸러지지 않습니다.
- **수정 제안**: 저장값 전체가 유효한 10진 정수인지 확인한 뒤 변환하고, 형식이 맞지 않거나 안전한 정수가 아니면 0을 반환합니다. 예를 들어 정규식 검사 후 `Number`와 `Number.isSafeInteger`를 적용할 수 있습니다.

## 3. 기존 review.md와 의견이 다른 항목

- 기존 리뷰 2차 검증의 **문제 A(두 열 전환 기준 900px가 명세의 768px와 다름)**는 현재 `spec.md`가 900px 기준으로 갱신되어 더는 불일치가 아닙니다. 코드의 `style.css:585`와 현재 명세가 일치합니다.
- 그 밖에 이전 문제 1~8의 수정 상태에 대해서는 코드상 이견이 없습니다. 다만 브라우저·로직 테스트를 다시 실행하지 않았으므로 동작 검증 결과를 새로 확인한 것은 아닙니다.
